# 型别教员测试结果看板

这是一个基于 Streamlit 的型别教员评估数据看板。上传导出的 Excel 后，可在“模拟机表现”和“训前讲评”之间切换，两套分析各有机型简报和总览驾驶舱，不混合分数。

## 当前能力

- 支持空客、波音、国产民机三类规则版本；
- 自动跳过空工作表并识别真实表头；字段匹配优先采用完整表头，忽略已删除字段，机型列位于表格后部也可识别；
- 解析训前讲评分数、模拟机各科分数、总分和扣分文本；
- 兼容空客、国产民机和波音导出表的不同列布局；通过评分表头定位模拟机扣分项，支持扣分列位于训前讲评前、总分后，以及机型等人员字段穿插其中的空客新版布局；
- 同一单元格混有“不扣分”和实际扣分时，保留明确的负分项，多个扣分值合计计入该评分项目；不依据满分反推扣分，也不恢复总分一致性验证；
- 简报支持切换“按机型类别”（波音、空客、国产民机）和“按具体机型”（B737、B787、A320、C919 等）；类别模式纳入全部国产民机记录；默认查看全部公司；
- 具体机型模式可筛选单一机型，筛选同时作用于简报、总览和明细下载；B737-800、737-800、B738 统一归入 B737，波音787 归入 B787，原始机型字段保留；只填写“空客”等类别的记录单列为“机型未明确”，不推断具体机型；
- 自动归并原表中明显的公司名称变体（如“东航北分/东航北京分公司”、“厦航/厦门航空有限公司”），选定公司后可手动增删纳入的原表单位名称；“上航”默认独立于“东航”，人工选择仅在当前会话生效；
- 在总览页查看每个上传文件的读取概况；
- 展示表内总分、失分、科目表现和扣分明细，供业务人员复盘；
- 公司和单位均分改为人员等权：先计算当前统计范围内每位教员的平均分，再对个人均分取平均；简报、总览、科目均分、最高/最低个人均分和得分分布均使用人员口径，原始评分记录数单独保留；
- 页面仅保留“机型简报”和“总览驾驶舱”，已移除“教员档案”“科目分析”；“人员均分明细”和“原始评分记录”仍可在总览内展开查看；
- 两种分析均提供人员均分、最高/最低个人均分、分布、公司/单位对比和各科目均分。讲评只用训前总分及训前科目得分，不借用模拟机分数；讲评不展示模拟机失分或扣分TOP 10，不推算未确认的满分与合格线；
- 扣分项目 TOP 10 先按评分项目合计所有扣分情况，再按累计失分排名；每个项目只显示一条柱和一个总数，扣分记录数按记录 ID 去重，具体标准在“具体扣分情况”中查看；
- 支持按机型类别、具体机型、公司及技术等级筛选；
- 下载内容跟随分析内容切换：原始评分CSV、分析明细Excel（原始记录、人员均分、科目均分）；仅模拟机分析额外包含扣分明细；
- 上传文件只在当前 Streamlit 会话内处理，不提交、不写入仓库。

## 本地运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 测试

```bash
python -m unittest discover -s tests -p 'test_*.py'
python -m py_compile app.py data_loader.py normalizer.py instructor_statistics.py statistics_runtime.py analysis.py company.py aircraft.py
```

上传验证应分别覆盖单独上传波音、空客、国产民机，以及切换公司筛选。简报与总览可能展示相同数据的图表，各图表已设置独立组件编号，避免单机型上传时发生重复组件错误。

统计实现位于 `instructor_statistics.py`；应用通过 `statistics_runtime.py` 按该文件源码哈希加载并缓存对应模块版本，避免线上进程持有旧模块时新增函数或参数不可用。`analysis.py` 仅保留旧导入路径的兼容导出。回归测试覆盖预加载旧模块后启动/上传、同进程源码变更后加载新版本，以及讲评/模拟机切换时的分数和图表隔离。

## 评分规则

`rules/` 中的 YAML 文件是从三份 Word 评分表整理出的规则版本。正式合格线尚未启用，应用展示原始得分和统计结果；模拟机另展示源文本中的扣分，不在看板内做总分一致性校验或合格性判断。讲评分不与模拟机分数相加或换算，相关数据口径由上游业务流程负责确认。

## 人员均分口径

在当前上传并筛选后的记录中，以归并后的公司名称和姓名识别人。公司名称变体属于同一公司时，同一教员的记录合并；不同公司的同名人员不合并。先过滤机型、公司和技术等级，再计算个人均分；未筛选机型时，个人均分包含当前范围内其所有机型的记录。原表单位对比在各原表单位内独立计算个人均分，不将单位均分再次平均来代替公司均分。

同一人的各评估员评分目前等权，个人均分计算完成后，每个有有效分数的人在公司均分中等权。空白或非数值分数不按0分计入，真实0分保留；全无有效分数的人员不参与均分和得分分布，但仍计入评估人数。中间均分不提前四舍五入，分数区间按未四舍五入的个人均分划分。

原表填写ID是评估记录ID，不是人员唯一编号；没有人员唯一编号时，同一公司内的重名人员仍需先在源数据中区分。系统不自动推断评估批次或把日期当作人员标识，不同批次、时间段请分别上传所需范围的数据。原始评分和扣分下载保持原记录粒度；扣分项目TOP 10仍汇总实际扣分，不对其累计失分改算个人均分。

## 公开部署注意事项

不要将真实 Excel、Word 评分表、人员姓名或其他敏感数据提交到 GitHub。代码仓库可以公开，但真实数据应通过上传使用，并在确认部署权限后再用于线上评估。

在 Streamlit Community Cloud 中创建应用时，入口文件选择 `app.py`，依赖文件使用根目录的 `requirements.txt`。

详细部署步骤见 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)。
