# 型别教员测试结果看板

这是一个基于 Streamlit 的型别教员评估数据看板。应用支持上传导出的 Excel，自动识别有效工作表、机型类别、评分字段和扣分明细，并提供可按公司选择的机型简报、总览驾驶舱、教员档案和科目分析。

## 当前能力

- 支持空客、波音、国产民机三类规则版本；
- 自动跳过空工作表并识别真实表头；字段匹配优先采用完整表头，忽略已删除字段，机型列位于表格后部也可识别；
- 解析训前讲评分数、模拟机各科分数、总分和扣分文本；
- 兼容空客、国产民机和波音导出表的不同列布局，保留波音表中位于训前讲评之前的模拟机扣分项；
- 简报支持切换“按机型类别”（波音、空客、国产民机）和“按具体机型”（B737、B787、A320、C919 等）；类别模式纳入全部国产民机记录；默认查看全部公司；
- 具体机型模式可筛选单一机型，筛选同时作用于总览、个人档案、科目分析和明细下载；B737-800、737-800、B738 统一归入 B737，波音787 归入 B787，原始机型字段保留；只填写“空客”等类别的记录单列为“机型未明确”，不推断具体机型；
- 自动归并原表中明显的公司名称变体（如“东航北分/东航北京分公司”、“厦航/厦门航空有限公司”），选定公司后可手动增删纳入的原表单位名称；“上航”默认独立于“东航”，人工选择仅在当前会话生效；
- 在总览页查看每个上传文件的读取概况；
- 展示表内总分、失分、科目表现和扣分明细，供业务人员复盘；
- 支持按机型类别、具体机型、公司及技术等级筛选；
- 支持导出标准化人员数据和扣分明细 Excel；
- 上传文件只在当前 Streamlit 会话内处理，不提交、不写入仓库。

## 本地运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 测试

```bash
python -m unittest discover -s tests -p 'test_*.py'
python -m py_compile app.py data_loader.py normalizer.py analysis.py company.py aircraft.py
```

上传验证应分别覆盖单独上传波音、空客、国产民机，以及切换公司筛选。简报与总览可能展示相同数据的图表，各图表已设置独立组件编号，避免单机型上传时发生重复组件错误。

## 评分规则

`rules/` 中的 YAML 文件是从三份 Word 评分表整理出的规则版本。正式合格线尚未启用，应用只展示原始得分、失分、风险等级和扣分明细，不在看板内做总分一致性校验或合格性判断；相关数据口径由上游业务流程负责确认。

## 公开部署注意事项

不要将真实 Excel、Word 评分表、人员姓名或其他敏感数据提交到 GitHub。代码仓库可以公开，但真实数据应通过上传使用，并在确认部署权限后再用于线上评估。

在 Streamlit Community Cloud 中创建应用时，入口文件选择 `app.py`，依赖文件使用根目录的 `requirements.txt`。

详细部署步骤见 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)。
